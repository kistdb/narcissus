# Security

Narcissus changes the indexes of people's databases, so a bug that could damage data, change a file it shouldn't, or run SQL it shouldn't, is treated as a security problem.

## Reporting a problem

Please report it privately, through GitHub's [private vulnerability reporting](https://github.com/kistdb/narcissus/security/advisories/new), rather than in a public issue. It helps to include:

- the Narcissus version (`narcissus version`) and your operating system;
- the command you ran, and a small database or SQL that shows the problem;
- what happened, and what you expected.

You'll hear back within a few days. Once a fix is ready, it's released and the report is published, with credit to you if you'd like it.

## Supported versions

Fixes go into the latest release. Narcissus is young, so please upgrade to it rather than expecting fixes to older versions.
